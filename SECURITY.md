# Security policy

Do not report suspected vulnerabilities, credentials, or personal data in a public issue.

Use GitHub's **Report a vulnerability** feature on this repository when private vulnerability reporting is enabled. Include the affected version or commit, impact, and a minimal reproduction that contains no real customer data or secret values.

If private reporting is unavailable, do not publish the details. Contact the repository maintainers through an organization-controlled private channel and ask them to enable or provide a monitored private reporting route. A public distribution must not begin until maintainers have verified that this reporting route is available and monitored.

For a suspected credential leak, do not copy or quote the value into a report. Give only the affected path and credential type so the owner can disable or rotate it. Do not rewrite repository history without the owner's approval.
